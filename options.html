DeepWatch

Bring your own API key (optional)

Transcripts and Notes work without any key, read directly from the video's own page with no third-party transcript service. A Gemini API key only unlocks Overview, translation, Explain, and Chat, and stays in this Chrome profile, sent only to Google's Gemini API. This open-source extension has no developer server or analytics.

AI provider

Google Gemini Supported in this version

DeepWatch uses Gemini for overviews, explanations, translation, note polishing, and chat. Create a Gemini API key.

The Gemini model name to call. Defaults to a fast, low-cost model; see the list of available Gemini models, for example gemini-2.5-pro for higher-quality, slower responses.

When you use AI features, Gemini receives the video transcript and relevant video context. Review Google's terms and pricing before saving.
Local remix Want to use another AI provider? Edit and copy a safe prompt for your coding agent Coding agent ready

You can edit the prompt directly. Complete these two steps before copying:

  1. Open the extracted DeepWatch project folder in your coding agent.
  2. Never include API keys in the prompt or chat. Enter them yourself after the code is ready.
Before copying, replace [PROVIDER] with the AI service you want to use instead of Gemini.
