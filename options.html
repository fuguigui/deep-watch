DeepWatch

Bring your own API key (optional)

Transcripts and Notes work without any key, read directly from the video's own page with no third-party transcript service. An API key only unlocks Overview, translation, Explain, and Chat, and stays in this Chrome profile, sent only to your chosen provider. This open-source extension has no developer server or analytics.

AI provider

DeepWatch sends the video transcript to this provider when you use AI features. Create an API key Ollama runs locally and usually doesn't need an API key. Leave this blank unless your server requires one.

Leave blank to use the provider's default:

A JSON object with url (or baseUrl + path), model, and optionally apiKey, headers, and format (one of "openai", "anthropic", or "gemini"; defaults to "openai"). Use this for a provider not listed above, e.g. Azure OpenAI or a self-hosted endpoint.

When you use AI features, your chosen provider receives the video transcript and relevant video context. Review its terms and pricing before saving.
